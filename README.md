# Capu — sitio de descarga y ventas

Página estática (sin build) para promocionar Capu: descarga de la última versión
(Android/Windows, leída en vivo de `neto-releases`), precios, y contacto de ventas
por WhatsApp.

## Actualizar

Es HTML/CSS/JS plano, sin dependencias ni paso de build. Editar `index.html`,
`style.css` o `script.js` y desplegar.

## Deploy

Conectado a Vercel como proyecto estático (framework: "Other"). Cada push a
`main` despliega a producción.
